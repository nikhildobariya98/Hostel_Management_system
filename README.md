# HostelRooms-Website
This is pure  HTML , CSS , SCSS , Javascript , bootstrap  Web project which responsive Hostel management system   website.



# Full HostelRooms management system (Community)

To preview and run the project on your device:

1. Open project folder in Visual Studio Code
2. In the terminal, run npm install
3. Run npm start to view project in browser


# language using

1) HTML
2) CSS
3) JAVASCRIPT
4) SCSS
5) BOOTSTRAP ( FRAMEWORK )
